Privacy Policy

Last updated: August 9, 2026

SnapGleam is a Chrome extension that lets users capture selected areas, page elements, the visible screen, full webpages, scroll-extended areas, and local HTML pages. This policy explains what information SnapGleam handles and how it is used.

1. Data SnapGleam handles

SnapGleam handles only the information needed to provide its screenshot features when you choose to use them.

Website content and screenshot data

When you start a capture, SnapGleam processes the visual content of the page or area you selected. Depending on the capture mode, the extension may also read page layout information such as dimensions, scroll position, and element geometry so it can select, scroll, crop, or stitch the requested capture.

Current page URL and title

SnapGleam may read the URL, hostname, and title of the active page during a user-initiated capture. These values are used locally for capture operation and for creating useful default filenames. SnapGleam does not maintain a browsing-history database.

Extension settings

Your SnapGleam preferences, such as capture format, after-capture behavior, toolbar behavior, and capture options, are stored locally using Chrome extension storage.

2. How the data is used

The information described above is used only to provide SnapGleam's user-facing screenshot functionality, including selecting content, capturing visible pixels, scrolling pages for long captures, stitching and cropping images, generating previews, copying images to the clipboard, and saving PNG, JPEG, or PDF files.

3. Local processing and storage

Screenshot processing is designed to occur locally in your browser. Captured images, page content, page URLs/titles, and SnapGleam settings are not sent to SnapGleam-operated servers by the extension.

When a preview is needed, screenshot data may be stored temporarily in local browser storage so the preview page can access it. The temporary capture is removed when it is consumed by the preview, and stale temporary captures are periodically purged. User settings remain stored locally until they are changed or the extension's local data is removed.

4. Data sharing and sale

SnapGleam does not sell user data. The extension does not transfer captured screenshots, website content, browsing information, or extension settings to advertising networks, data brokers, analytics providers, or other third parties.

5. Accounts, analytics, ads, and tracking

SnapGleam does not require a user account. The current extension does not include advertising or third-party analytics, and it does not use captured content or browsing information for advertising, profiling, or credit-related purposes.

6. Permissions

SnapGleam uses Chrome extension permissions only to provide its screenshot workflow. These permissions include temporary access to the active tab, script injection for capture controls and page measurement, local storage for settings, downloads for saving files, an offscreen document for local image processing, clipboard access for copying captures, and context menus for user-invoked capture shortcuts.

7. Local HTML files

If you enable Chrome's “Allow access to file URLs” option for SnapGleam, the extension can capture local file:// pages that you explicitly open and choose to capture. This access is used for the same screenshot purpose described in this policy.

8. Chrome Web Store Limited Use

SnapGleam's use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. User data is used only as necessary to provide or improve SnapGleam's disclosed single-purpose screenshot functionality.

9. Changes to this policy

If SnapGleam's data practices materially change, this policy will be updated and the change will be disclosed as required before the new practice applies.

10. Contact

For privacy or support questions, please use the developer contact or support method shown on SnapGleam's Chrome Web Store listing.
