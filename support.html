SnapGleam — Screenshot & Full Page Capture

Local HTML pages

To capture a local file:// page, open Chrome's extension management page, open SnapGleam's details, and enable Allow access to file URLs. Then open your local HTML file in Chrome and start a SnapGleam capture.

Protected Chrome pages

Chrome restricts extensions from injecting scripts into protected browser pages such as chrome:// pages, the Chrome Web Store, and some extension pages. SnapGleam does not attempt to bypass these browser security restrictions.

Keyboard shortcuts

Open SnapGleam and choose Shortcuts to review or change the available Chrome keyboard shortcuts for Area, Full Page, Element, and Visible capture modes.

Capture problems

If a long page changes while it is being captured, wait for the page to settle and try again. Dynamic pages with lazy-loaded or sticky content can change dimensions during scrolling.

Contact

For bug reports, questions, or other support requests, use the developer contact or support method provided on SnapGleam's Chrome Web Store listing. When reporting a capture problem, include the SnapGleam version, Chrome version, page type, capture mode, and a short description of what happened. Do not send sensitive screenshots unless they are necessary for the issue and you are comfortable sharing them.
